## TL;DR

Initial launch of the SkillWiki HTTP MCP service with OAuth authentication and multi-vault architecture.

## Overview

This note provides a baseline concept document within the demo vault. It allows review prompts and test cases to query milestone information and test CAS-based page publications.

## Key Milestones

1. **HTTP MCP Core:** Robust streamable HTTP MCP server implementation supporting 15 deterministic tools.
2. **OAuth Authorization:** Password-based operator authentication with PKCE support conforming to RFC 8414 and RFC 9728.
3. **Multi-Vault Routing:** Isolated vault roots and S3 prefixes with fail-closed permissions.
4. **App Directory Listing:** Packaged listing bundle for the ChatGPT App ecosystem.
