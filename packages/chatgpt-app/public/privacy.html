Privacy Policy

Last updated: September 2026

1. Overview & Architecture

SkillWiki is an operator-hosted knowledge base system. It exposes a Model Context Protocol (MCP) endpoint that allows AI clients like ChatGPT to read and write notes in an authorized vault on behalf of the operator.

2. Authentication & Data Access

ChatGPT connects via OAuth 2.0 PKCE using the operator-configured password for the specific vault. No third-party identities (such as Google or email logins) are accepted or stored. Host-id bearer tokens remain a separate infrastructure plane and are never exposed to ChatGPT or end-user sessions.

3. Data Transferred Through MCP

When you use the SkillWiki ChatGPT App, ChatGPT sends tool arguments (such as search queries, read paths, and markdown content for note captures or page publications) to the configured MCP server endpoint over HTTPS. Only content explicitly requested or authored in the chat is transmitted.

4. Data Storage and Retention

Notes, transcripts, and published pages are stored within the operator's private vault storage (local filesystem and backed up to configured S3 object storage). Data retention, backup policies, and access controls are entirely controlled by the vault operator.

5. Third Parties & Telemetry

The SkillWiki MCP server does not collect usage analytics, advertising telemetry, or tracking cookies. Data sent to OpenAI or processed by ChatGPT is governed by OpenAI's respective privacy policy.

6. Contact

For questions or assistance regarding privacy and data practices, please consult our Support page.
