# skillwiki v0.10.60

Patch release. Follow-up to v0.10.59 vault hygiene.

## Changes

- **vault-sync status:** leaf `last_push_age` prefers `wiki-push-result.state`
  (same as doctor). Journal fallback skips JSON lines and requires a
  timestamped `OK push` / `FAIL` line. Detail is truncated so lint-delta
  envelopes cannot flood the table.
- **wiki-push:** no longer appends the raw lint-delta JSON envelope to
  `wiki-push.log`. Keeps the one-line `LINT-DELTA full=…` summary.
- **Hygiene:** `.drafts/` is required gitignore + rclone exclude + doctor
  scratch. Published typed pages are not ignored. `mergeGitignore` does not
  duplicate the local-scratch comment block.

```bash
skillwiki init --target "$VAULT" --domain existing --write-gitignore
git -C "$VAULT" rm --cached -r -- .drafts
```

Leave draft files on disk. Do not delete `.skillwiki/work-complete/`.

Redeploy vault-sync leaf:

