# v0.10.126

Patch. Ships the conservative snapshot Git repair helper that was missing
from the 0.10.125 runtime payload during the 2026-11-04/05 unpushed-snapshot
stall.

- Packages `wiki-git-repair-v3.sh` beside `wiki-snapshot.sh`. Installer
  wildcard and `deploy-runtime.py` copy it into the installed inventory and
  immutable runtime payload.
- Snapshot classification treats ahead/unpushed HEAD as promotion, not
  divergence. A failed GitHub push leaves the candidate for the next run
  and does not invoke repair.
- Repair preserves equal/ahead histories, fast-forwards behind histories
  without autostash, and refuses true divergence, locks, and unsafe rebase
  state. Missing helper is a hard error with a stable diagnostic.
- Failed semantic-preview attempts retain preview JSON in the journal.
