# v0.10.127

Patch. Bounds Claude/Codex SessionStart cost and aligns HTTP memory recall
with the CLI so AMH isolates and MCP clients see the same vault bodies.

- SessionStart `additionalContext` injects compact
  `using-skillwiki/activation.md` instead of the full SKILL.md.
- Isolate collect directories named `amh-iso-*` or `agent-memory-collect.*`
  omit Dynamic Session Memory (weekly-work-plan / session-brief bleed).
- `skillwiki memory recall` and HTTP `wiki_memory_recall` read live vault
  pages and hash the body after frontmatter. A missing or stale
  `.skillwiki/memory` cache no longer empties recall.
- HTTP `wiki_memory_recall` grows optional `limit` (1..50, default 10).

Does bump npm `skillwiki` and the Claude/Grok plugin manifests. Production
HTTP MCP still needs a daemon deploy to serve the live-recall path.
