# skillwiki v0.10.33

Patch release. Fixes the plutil-less launchd plist validator on CI hosts and
hardens llm-wiki plugin metadata drift guards.

## Fixes

- **Multi-line XML comments in plutil-less plist fallback:** the fallback
  `platform_launchd_plist_validate` only skipped single-line `<!-- ... -->`
  comments, but the shipped launchd templates carry a multi-line comment. On
  hosts without `plutil` (Ubuntu CI) every rendered plist was rejected as
  "plist XML structure is invalid", failing all macOS-launchd install
  scenarios. The fallback now tracks comment state until the closing `-->`
  (comments are ignorable XML; `plutil` accepts them) and treats an
  unterminated comment as invalid. Regression tests drive the shipped
  validator against plists rendered from the shipped templates, plus a full
  end-to-end install scenario for plutil-less hosts.
- **Plugin metadata drift guards:** new plugin-metadata regression fixtures
  cover normalized documentation/mirror inventory, stale documentation
  inventory reporting, stale release markers, missing marketplace sources,
  hidden mirror extras, and broken mirror links; CI enforces llm-wiki plugin
  inventory contracts and keeps the Codex inventory current.
