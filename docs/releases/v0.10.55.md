# skillwiki v0.10.55

Patch release on top of v0.10.54. Completes last-op file lists so
path-scoped auto-commit includes command side effects.

## Fixes

- **`session-brief --write` last-op includes `log.md` and `index.md`**
  when those files actually change.
- **`archive --cascade --apply` last-op includes rewritten referencing
  pages and `index.md`**, not only the archived path and tombstone.
