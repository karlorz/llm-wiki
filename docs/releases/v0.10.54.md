# skillwiki v0.10.54

Patch release. Stops `skillwiki log-append` auto-commit from sweeping
pre-existing dirty vault WIP into the same commit.

## Fixes

- **`postCommit` stages last-op files only.** When last-op lists paths (the
  `log-append` case), auto-commit adds and commits those paths with an
  explicit pathspec so already-staged unrelated files stay out of the
  new commit.
- **`log-append` last-op includes the event path.** A successful append
  with an immutable log event records both `log.md` and
  `meta/log-events/...`.
- **Empty last-op `files` still auto-commits.** `backup restore` leaves
  `files: []` on purpose; that path falls back to
  `stageVaultContentChanges` so restored content is still committed.
