# skillwiki v0.10.58

Patch release. Treats `.skillwiki/work-complete/` retry journals as
local hygiene, not GitHub source of truth.

## Changes

- **Init:** always writes or merges a vault `.gitignore` for local
  scratch (`work-complete/`, `last-op.json`, locks, memory/graph/vectors).
  Does not ignore `session-brief.*` or `agent-memory-trends/`.
  `--no-gitignore` skips. `--write-gitignore` repairs an existing vault
  without rewriting `SCHEMA.md`.
- **Doctor:** GitHub-synced vaults warn when those gitignore patterns
  are missing (`vault_gitignore_hygiene`) or already tracked
  (`vault_gitignore_tracked_scratch`).
- **Rclone + status:** `wiki-push-filters.txt` and doctor/health/status
  required excludes include `work-complete/` and `last-op.json`.
- **Commit pathspec:** `stageVaultContentChanges` unstages the same
  scratch paths after `git add -A`.

## Live vault follow-up

```bash
skillwiki init --target "$VAULT" --domain existing --write-gitignore
git -C "$VAULT" rm --cached -r -- .skillwiki/work-complete
```

Redeploy vault-sync leaf so rclone stops copying journals:

```bash
bash packages/vault-sync/skills/vault-sync-install/install.sh --execute --role leaf
```
