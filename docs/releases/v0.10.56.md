# skillwiki v0.10.56

Patch release on top of v0.10.55. Stops vault-relative paths after
`Session:` / `token:` labels from counting as secrets.

## Fixes

- **Token matcher G4:** `isNonSecretTokenCapture` ignores values that
  contain `/`. Markdown related lines such as
  `Session: raw/transcripts/….md` are file references, not credentials.
- **Unchanged policy:** `sess_…` identifiers and pure-hex hyphenated
  session UUIDs still flag. Other matchers (`api_key`, `password`,
  `provider_key`, …) are unchanged.

This unblocks leaf `lint-delta` / wiki-push when a new raw transcript
uses `Session:` as a related-capture label.
