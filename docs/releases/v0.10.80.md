# v0.10.80

Patch. Land `wiki_query` work/all scope, add `writer_id` to `wiki_capture` success, and expose `compact_activation` sha256/bytes on `wiki_context`.

- `wiki_query` advertises `scope=typed|work|all` (default `typed`). Setup and open-work queries can query `scope=work` or `scope=all` without reopening historical-cycle ranking.
- `wiki_capture` success receipt includes `writer_id` from `ctx.hostId` (`chatgpt-web` under OAuth, host id under bearer).
- `wiki_context` includes `compact_activation: { instructions_sha256, instructions_bytes }` computed over the exact `MCP_INSTRUCTIONS` string sent on initialize.
