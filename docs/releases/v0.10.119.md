# v0.10.119

Patch release. Reclaims a dead same-host SkillWiki HTTP MCP workspace
control-plane lock so an unclean daemon exit cannot crash-loop
`CONTROL_PLANE_LOCKED`.

- `WorkspaceStore` reclaims `workspaces.lock` only when the record parses
  strictly, the host matches, and `process.kill(pid, 0)` returns `ESRCH`.
- Reclaim is rename-verify-restore: the stale bytes move into `recovery/`,
  the moved owner id is re-checked, and a mismatch restores the live lock.
- Live PID, `EPERM`, foreign host, malformed or non-UUID records stay
  fail-closed. Reclaim is never based on lock age.
