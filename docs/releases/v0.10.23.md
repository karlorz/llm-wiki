# skillwiki v0.10.23

Patch release that makes Obsidian Web Clipper a supported asynchronous raw
ingress path and restores the raw-evidence preservation boundary across the
CLI, skills, health, and session context.

## Web Clipper and pending sources

- **Vault-installed capture template:** `skillwiki init` creates and preserves
  `_Templates/web-clipper/llm-wiki-clippings.json` plus a short import guide.
  Import it from Obsidian Web Clipper settings in each browser profile that
  captures into the vault.
- **Lifecycle-first vault tree:** new vaults include active source roots plus
  `raw/archived/{articles,papers,transcripts}` and
  `raw/duplicates/{articles,papers,transcripts}`.
- **Pending inventory:** `skillwiki sources pending` lists uncited active
  articles and papers with deterministic schema, capture-date, age, channel,
  storage, reference, and lifecycle classification.
- **Explicit query channel:** `skillwiki query "..." --include-pending` keeps
  pending captures separate from typed ranking in `pending_sources`.
- **Editorial events:** `skillwiki sources disposition` records append-only
  reviewed/deferred/duplicate/out-of-scope/superseded/reopened decisions.
- **Awareness:** health reports a nonblocking `source_lifecycle` component and
  session briefs show at most five recent pending sources.

## Raw preservation and assets

- Existing raw content/frontmatter is never autonomously rewritten. Archive,
  stale, and dedup apply use attended state-bound approval and preserve exact
  bytes under `raw/`.
- Raw archive now targets `raw/archived/...`; dedup preserves duplicate bytes
  under `raw/duplicates/...`; legacy `_archive/raw/` remains read-compatible
  only.
- Lint, drift, and path-length automation report raw findings without rewriting
  evidence. Ordinary `remove` refuses `raw/**`.
- Exceptional permanent disposal requires one exact raw path, attended TTY,
  live approval token, unchanged bytes/references, durable delete intent, and
  append-only approval/completion events.
- `raw/assets/**` is a flexible stable pool with no fixed internal taxonomy.
  Use explicit vault-root embeds such as `![[raw/assets/example/diagram.png]]`.
  Referenced asset paths freeze after capture and routine source lifecycle
  operations never move them. Remote HTTP(S) images remain external
  dependencies unless separately captured.

## Compatibility and rollout

- Legacy Web Clipper frontmatter (`source` + `created`) is classified without
  mutation and remains searchable through the lifecycle inventory.
- Re-initializing a vault preserves customized Web Clipper template/readme
  copies byte-for-byte.
- This is a CLI/plugin update only; no vault-sync runtime redeploy or automatic
  live-vault migration is required.

```yaml
breaking_change: false
redeploy_required: cli-plugin-update
vault_sync_runtime_redeploy_required: false
live_vault_migration_required: false
```

```bash
npm install -g skillwiki@0.10.23
# or: skillwiki update

skillwiki --version
skillwiki sources pending
skillwiki query "recent clipped sources" --include-pending
```
