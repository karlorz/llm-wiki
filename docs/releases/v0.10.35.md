# skillwiki v0.10.35

Patch release. Extends the `ingested_by` enum so raw articles captured by the
deep-research agent and export-wiki tool validate correctly.

## Fixes

- **`ingested_by` enum extended:** `packages/shared/src/schemas.ts` now accepts
  `"deep-research"` and `"export-wiki"` in addition to `wiki-ingest`, `proj-work`,
  and `manual`. The deep-research skill's `vault-pipeline.md` contract specifies
  `ingested_by: "deep-research"` for raw articles it captures, but the Zod enum
  only accepted three values. This caused 5+ existing raw articles to fail
  `skillwiki validate` with `Invalid enum value`. The enum is now aligned with
  the real producers in the vault.

## Docs

- **agent-memory-trends README:** documents all 7 discovery lanes (was 4),
  including `org_watchlist`, `topic_lane`, and `velocity`. New "Query string
  rules" section explains that the collector's `qualifyQuery()` appends date
  filters automatically from lane `window_days`/`date_field` params — query
  strings must NOT contain `{{...}}` template syntax or `stars:>{{N}}`
  qualifiers. Updated dedupe TTL from 14 to 7 days. Added weekly deep-research
  coverage sweep to Periodic Review section.
- **deep-research skill (vault-pipeline.md):** new "Worked Example:
  Coverage-Sweep Pattern" with prompt template, expected artifacts, and
  post-run validation checklist. Documents the `ingested_by` enum requirement
  (v0.10.35+).
- **deep-research skill (SKILL.md):** periodic coverage sweep added to "When to
  Use" section. `ingested_by` enum note added to Tool Usage section.
