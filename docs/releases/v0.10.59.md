# skillwiki v0.10.59

Patch release. Expands vault hygiene so GitHub-synced vaults ignore
host scratch and Obsidian plugin binaries, matching rclone.

## Changes

- **Init / gitignore:** required local-scratch patterns now include
  `.playwright-cli/`, `.pytest_cache/`, `.snapshots/`, `.superpowers/`,
  `.antigravitycli/`, `.obsidian/plugins/*/main.js`, and `.claude/dev-loop/`.
  Still does not ignore `session-brief.*`, `agent-memory-trends/`, plugin
  `manifest.json`, `custom-sort/data.json`, or `remotely-save/styles.css`.
- **Doctor:** GitHub-synced vaults warn when those patterns are missing
  or when plugin `main.js` / host scratch is still tracked.
- **Rclone:** `wiki-push-filters.txt` required excludes add `.superpowers/`,
  `.antigravitycli/`, and `.claude/dev-loop/` (plugin `main.js` was already
  excluded).

## Live vault follow-up

```bash
skillwiki init --target "$VAULT" --domain existing --write-gitignore
git -C "$VAULT" rm --cached -- \
  .obsidian/plugins/custom-sort/main.js \
  .obsidian/plugins/remotely-save/main.js
# plus any tracked .playwright-cli / .snapshots / .antigravitycli / .claude/dev-loop
```

Obsidian does not auto-install from `manifest.json`. Keep manifests and
settings in git; each host installs the community plugins once. Files
untracked with `git rm --cached` stay on disk.

Redeploy vault-sync leaf so rclone picks up the new excludes:

```bash
bash packages/vault-sync/skills/vault-sync-install/install.sh --execute --role leaf
```
