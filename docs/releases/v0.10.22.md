# skillwiki v0.10.22

Patch release that closes the protected snapshot-worktree authoring guidance
gap: agents must not treat `/root/wiki-git` as an ordinary authoring surface.

## Features

- **`skillwiki project-page publish`:** managed Layer-3 architecture publisher
  limited to `projects/{slug}/architecture/*.md`. Regenerates project
  `knowledge.md`, never mutates root `index.md` for architecture pages, and
  never invokes systemd or Git promotion.
- **Publication approval tokens (`swpub1…`):** dry-run emits a deterministic,
  target-bound token; `project-page publish --write` requires
  `--approve <token>` before preflight or mutation.
- **Optional `page publish --approve`:** same shared token contract; omitting
  `--approve` remains backward compatible.
- **Host-local recovery journals:**
  `~/.skillwiki/publication-operations/{vault-identity}/{operation-id}.json`
  with monotonic phases and deterministic forward recovery.
- **Log kind `project-page-publish`:** immutable events and compatibility
  markers (`<!-- skillwiki-project-page-publish:{operation-id} -->`).

## Skills

- **`wiki-sync`:** host-aware authority matrix; removes executable recipes that
  rsync/copy into snapshot worktrees, `git reset --hard` there, or run
  `skillwiki sync push /root/wiki` on protected snapshotters.
- **`proj-decide`:** Layer-3 architecture ADRs must use
  `project-page publish` with dry-run review and approved write.

## Rollout

```yaml
breaking_change: false
redeploy_required: cli-plugin-update
vault_sync_runtime_redeploy_required: false
```

```bash
npm install -g skillwiki@0.10.22
# or: skillwiki update

skillwiki --version   # expect 0.10.22
skillwiki doctor
skillwiki project-page publish --help
skillwiki page publish --help   # includes --approve
```

Do **not** redeploy vault-sync runtime for this release unless other work
requires it. On protected snapshotters, author only via the host-resolved live
vault (`skillwiki path`); never author, commit, or push in `/root/wiki-git`.
