# v0.10.120

Patch release. Stops SkillWiki HTTP MCP from dying when a client
resets the TCP connection (`ECONNRESET` / `EPIPE` / `ECONNABORTED`).

- Socket, `clientError`, and request-handler rejections ignore connection
  resets instead of becoming unhandled crashes.
- After listen, a durable `server.on("error")` remains; `/health` still
  answers after a mid-request abort.
- SIGTERM/SIGINT still close the workspace store. Unrelated errors are
  not swallowed.

after release CI is green, then verify `/health` readiness and
