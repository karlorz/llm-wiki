# v0.10.109

Patch release. Fixes Windows MCP-only leaf configuration discovery and uses
the MCP SDK for live doctor/connect verification.

- Resolves user configuration from explicit home, nonblank HOME, USERPROFILE,
  then the operating-system home; doctor reports the absolute config path
  without exposing configuration values.
- Shares negotiated MCP initialization, JSON/SSE handling, optional session
  headers, a bounded ten-second deadline, and transport cleanup across probes.
- Makes connect verification fail on invalid initialization or status results,
  and uses the same effective URL/token for doctor and status checks.
- Clarifies local versus live wiki reads, Windows launchers/ACLs, and safe
  operator-controlled credential configuration in onboarding skills.

Upgrade Windows clients with `npm.cmd install -g skillwiki@0.10.109`, then
verify `skillwiki.cmd --version`, `skillwiki.cmd config path`, and
`skillwiki.cmd doctor --check-mcp`. No credential rewrite or production MCP
daemon restart is required for these client fixes. Existing plugin sessions
must be refreshed separately to load revised onboarding instructions.
